# 🍎 Apple Stock Price Prediction (30-Day Forecast)

## 📌 Project Overview
This project is a **Machine Learning-based Time Series Forecasting System** that predicts **Apple (AAPL) stock prices for the next 30 days**.  
It leverages historical stock data and advanced feature engineering techniques to capture market trends and generate accurate short-term predictions.

The system is deployed as an **interactive Streamlit web application**, allowing users to visualize stock trends and generate real-time forecasts.

---

## 🎯 Objectives
- Predict Apple stock prices for the **next 30 days**
- Analyze **short-term and long-term trends**
- Apply **machine learning models** for forecasting
- Provide an **interactive dashboard** for users

---

## 🧠 Key Features
- 📊 Historical stock price visualization  
- 📈 30-day future price prediction  
- ⚙️ Advanced feature engineering (MA, EMA, Volatility, Lag features)  
- 🔁 Recursive multi-step forecasting  
- 🌐 Interactive Streamlit web application  
- ⚠️ Data validation and error handling  

---

## 🛠️ Tech Stack
- **Programming Language:** Python  
- **Libraries:** Pandas, NumPy, Scikit-learn, XGBoost, Matplotlib  
- **Deployment:** Streamlit
